功能特性

八个关键设计，让报警更及时、更可靠

姿态识别报警
HUSKYLENS 2 姿态算法，三个学习过的姿态 ID 对应三种状态，识别即响应。
振动与警报同时进行
报警开始时方向盘振动马达立即启动，与蜂鸣、闪灯并行，报警结束自动停止。
检测永不卡顿
报警、预警、振动分别运行在独立后台循环，主循环每 50ms 照常轮询姿态。
疲劳自动升级
疲劳征兆持续超过阈值仍未恢复，自动升级为重度报警（疲劳升级毫秒 参数）。
开机自检
上电短鸣一声、绿灯亮 0.5 秒，表示初始化完成；自检不响说明 HUSKYLENS 未连好。
丢失保护
连续 5 秒检测不到司机，自动停振动马达并清灯，防止无人驾驶车辆失控。
全参数可调
11 个可调参数集中在开机初始化区，改数值即可调整行为，无需改动逻辑。
积木便签注释
积木视图关键位置带中文便签，JS 视图同步注释，教学与二次开发更轻松。

一块扩展板承载全部输出：驱动、灯、蜂鸣器

硬件数量用途

接线说明
  • HUSKYLENS 2 → micro:bit I2C 引脚：P19（SCL）、P20（SDA），接 RobotBit 的 I2C 座即可
  • 方向盘振动马达 → RobotBit M1 接线端子（代码使用 Motors.M1A）
  • 蜂鸣器 / RGB 灯 → 使用 RobotBit 板载件，无需接线
  • 供电：装好 18650 电池后用 RobotBit 的电源开关开机
HUSKYLENS 2 姿态训练
  1. 1打开 HUSKYLENS 2，进入（或切换到）姿态识别算法
  2. 2对准司机的清醒姿态（如端正坐姿），学习并保存为 ID 1
  3. 3对准打瞌睡姿态（低头 / 闭眼），学习并保存为 ID 2
  4. 4对准疲劳征兆姿态（频繁点头 / 揉眼等过渡姿态），学习并保存为 ID 3
  5. 5建议每个姿态在多种光线、角度下多次学习，提高识别稳定性

具体按键与菜单位置以 HUSKYLENS 2 固件实际界面为准。

运行状态变量
程序自动维护，无需修改
变量作用
动作中有报警 / 预警动作正在后台执行（此时主循环只检测、不重复派发）
报警请求 / 预警请求 / 振动请求循环 1 → 循环 2 / 3 / 4 的任务请求标志
丢失停机已因丢失姿态而停机，避免重复执行停机动作
首次疲劳时间疲劳征兆首次出现的时间，用于持续计时升级
最后检测时间最近一次检测到姿态的时间，用于丢失判断
四个并行循环
循环职责节奏
循环 1 · 主循环读取姿态 → 按 ID 亮灯 → 派发请求 → 丢失保护 → 疲劳升级判断每 轮询间隔（50ms）一轮
循环 2 · 重度报警蜂鸣 + 红灯闪烁，结束时停止振动有报警请求时执行
循环 3 · 轻度预警快速短鸣有预警请求时执行
循环 4 · 同步振动与报警声光同时启动方向盘振动马达有振动请求时执行

使用方法

  1. 1

    打开 makecode.microbit.org

  2. 2

    点击 导入 → 导入 URL，粘贴 https://github.com/Gsjsjzhznsz/driver 并导入

  3. 3

    积木视图中，带黄色便签图标的积木可点开查看中文说明

  4. 4

    下载 .hex 到 micro:bit，装上 RobotBit 与 HUSKYLENS 2 即可运行

若浏览器中打开的还是旧版项目，请 导入 → 从 GitHub 重新导入一次（MakeCode 会缓存已打开的项目）。
二次开发建议

换振动端口

方向盘振动马达目前接 M1，如接其他端口，把积木中的 Motors.M1A 改为对应端口即可。

升级策略

调节 疲劳升级毫秒（默认 10 秒）改变灵敏度；也可改成「连续 N 次疲劳征兆」的计数式升级。

更多输出

在循环 2 中加入无线电通知（radio），把报警状态发给随车监护设备。

记录数据

利用 micro:bit 数据记录（datalogger）扩展记录每次报警时间，便于事后分析。
